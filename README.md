# Mumla для Hytera P60

Доработанная версия [Mumla](https://gitlab.com/quite/mumla) — клиента Mumble для Android —
под PoC-рацию Hytera P60.

Что добавлено:

- штатная кнопка PTT работает, когда приложение свёрнуто или экран выключен
  (служба специальных возможностей «Mumla PTT»);
- приём системных сигналов «PTT нажата / отпущена», которые рассылают PoC-рации;
- пункт «Кнопка PTT в фоне» в настройках звука.

## Установка

1. Откройте раздел **Releases** этого репозитория и скачайте `mumla-p60.apk`.
2. Установите файл на рацию.

## Настройка

1. Настройки → Звук → режим передачи **Push to Talk**.
2. «Клавиша PTT» — нажмите штатную кнопку PTT рации.
3. «Кнопка PTT в фоне» — включите службу **Mumla PTT** в специальных возможностях.
